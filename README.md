# 아라호 관제센터 🚀

중학교 1학년 과학 Ⅶ-1 「태양계 구성과 태양 활동」 수업·논술형 평가 연습 웹앱.

- 📚 미션 학습: 4개 장(태양계 구성원 / 지구형·목성형 행성 / 태양의 특징과 활동 / 지구에 미치는 영향), 카드식 학습 + 퀴즈 + 한 줄 논술
- 🔭 미스터리 천체 수배 파일: 단서로 천체를 추리하는 게임
- ✍️ 논술 시험: 실제 평가와 같은 구조의 평행 문항 3개, 자동 점검 + AI 코치 피드백(Gemini API)
- 📋 선생님 탭: 학생 제출 코드로 학급 기록 확인, AI 키 설정

## 사용법

1. GitHub Pages로 배포하면 `index.html`이 그대로 열립니다.
2. 선생님 탭(교사 코드 입력) → Gemini API 키 저장 → "학생 배포용 링크"를 QR로 나눠주면 학생 기기에서 AI 코치가 켜집니다.
3. 학생 기록은 각 기기에 저장되고, 홈의 "제출 코드"를 복사해 선생님께 보내면 선생님 탭에서 모아 볼 수 있습니다.

API 키는 저장소에 넣지 마세요. 키는 각 기기의 브라우저에만 저장됩니다.
