# 아라호 관제센터 🚀

중학교 1학년 과학 Ⅶ-1 「태양계 구성과 태양 활동」 수업·논술형 평가 연습 웹앱 (16:9 전자칠판·태블릿 대응).

- 📚 **미션 학습** 5개 장 — 전체 화면 슬라이드. 태양계 구성원 / 행성의 특징과 분류 / 태양의 표면·대기와 활동 / 지구에 미치는 영향 / (보너스) 천체 망원경과 관측. 교과서 사진, 공전 애니메이션, 태양 활동 시뮬레이터, 격납고 분류 게임, 한 줄 논술.
- 🔭 **수배 파일** — 흐린 사진과 단서로 천체를 추리.
- ✍️ **논술 시험** — 실제 평가와 같은 3문항(2+2+6). 문항마다 필요한 제시문·자료만 같은 화면에.
- 📋 **센터장** — 학급 전체의 점수·진도·한 줄 논술·시험 답안·AI 피드백 실시간 대시보드.

## 설치 (5분) — 구글 시트 + Apps Script

1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. 편집기 내용을 지우고 이 저장소의 **`Code.gs`** 전체를 붙여넣기 → 저장
3. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → 배포 → 권한 허용 → 웹 앱 URL 복사
4. `index.html` 맨 위 `const API = '';` 따옴표 안에 URL 붙여넣기 (깃허브에서 ✏️로 바로 편집 가능)
5. 시트에 자동 생성된 **설정** 탭에서 `GEMINI_KEY`(aistudio.google.com 발급)와 `PIN`(센터장 코드) 입력

이후 학생이 반·번호·이름으로 입장하면 모든 기록이 시트의 **학생**(현재 상태)·**기록**(모든 글과 AI 피드백) 탭에 자동으로 쌓이고, 앱의 센터장 탭(PIN 입력)에서 바로 볼 수 있습니다. API 키는 시트 안에만 있고 코드·학생 기기에는 들어가지 않습니다.

## 폴더

- `index.html` — 앱 전체
- `Code.gs` — Apps Script 백엔드 (시트 저장 + 교신 게시판 + Gemini 피드백 중계)
- `GEM_PROMPT.md` — Gemini Gem을 따로 만들고 싶을 때 쓰는 논술 코치 프롬프트 (앱 내 코치와 동일 규칙)
- `img/` — 교과서에서 추출한 수업용 사진 (NASA 등 공개 자료 위주)
- `docs/` — 자료실 PDF (미션별 정리 자료, 태블릿용으로 용량 축소)
